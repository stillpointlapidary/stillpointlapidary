## 5. Repo Basics for a Fresh Clone

### Clone command
```bash
git clone https://github.com/stillpointlapidary/stillpointlapidary.git
cd stillpointlapidary
```

### Default branch
`main`

### Site type
**Pure static HTML.** No build tool, no package manager, no npm, no bundler. The site is a collection of `.html`, `.css`, and `.js` files served directly. There is no `package.json`, `Makefile`, or build command.

### Dependencies
None to install. The site references:
- Google Fonts (loaded via CDN `<link>` in each page's `<head>`)
- Supabase storage (for stone images and SVG icons, loaded via URL — no credentials needed for public read access)
- `styles.css` — site-wide stylesheet (checked in at repo root)
- `stones/enc-icons.css` — encyclopedia icon stylesheet (checked in, maps 57 icon classes to Supabase SVG URLs)
- `stones/enc-nav.js` — encyclopedia navigation array (checked in)

### Environment variables
None required for the static site itself. No `.env` file needed.

### To view locally
Open any `.html` file directly in a browser, or serve from localhost with any static server:
```bash
# Python (no install needed on most machines)
python -m http.server 8000
# then open http://localhost:8000
```

### Deploy
No CI/CD pipeline is visible in the repo. Deployment appears to be manual push to the remote. The site is likely hosted via GitHub Pages or a similar static host pointed at the `main` branch. Confirm hosting setup with Christie before pushing.
