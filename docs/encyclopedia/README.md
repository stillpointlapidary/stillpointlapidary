# Canonical Encyclopedia Starter Pack

This starter pack creates the production-data system without inventing values for the remaining catalog.

Included:

1. `ENCYCLOPEDIA-PRODUCTION-DATA.csv`
   - Schema for locked page-production values
   - One completed, approved row for Green Aventurine

2. `ENCYCLOPEDIA-MINERAL-DATA.csv`
   - Schema for locked mineral facts
   - One corrected row for Green Aventurine

3. `ENCYCLOPEDIA-PRODUCTION-PACKET-RULES.md`
   - Preflight, stop conditions, locked-data boundaries, and final compliance question

Recommended repository location:

`docs/encyclopedia/`

The remaining stones should be populated only from authoritative catalog, Supabase, navigation, chakra, and editorial sources. Do not bulk-fill missing values by inference.
